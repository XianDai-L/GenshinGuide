# 原神攻略助手（Genshin Guide Overlay）

游戏内悬浮窗攻略助手。在原神（无边框窗口化）中按住 **Alt** 释放鼠标后，可以点击 / 拖动 / 锁定本窗口，输入问题即时获得攻略回答。

适合直播时挂在游戏角落使用，也适合边玩边查资料。

## 功能

- **弹幕式悬浮窗**：窗口置顶、可拖动、可锁定、不抢游戏焦点，游戏中按住 Alt 即可操作
- **多级检索**：字段级精确匹配 → 关键词库 → RAG 向量检索 → Agent 多工具问答，命中即答
- **Agent 智能问答（可选）**：配置 API Key 后，LLM 可多步调用本地查询工具，回答组合问题：
  - "胡桃怎么养"（自动组合武器 / 圣遗物 / 天赋 / 配队）
  - "天赋6升7要什么材料"（按等级段精确）
  - "勤劳的教导什么时候刷"（周几 + 秘境）
- **多轮对话**：可开启最近 5 轮上下文，支持省略主语的追问（如"那最高提升呢"）
- **可观测**：每次问答记录完整决策轨迹（`logs/qa.jsonl`），内置"日志与统计"面板，支持评估与优化

## 环境要求

- Python 3.9+
- Windows（悬浮窗目标环境为原神无边框窗口化）

## 快速开始

```bash
pip install -r requirements.txt
python setup_data.py      # 拉取数据 + 构建索引（约 25 分钟）
python main.py            # 启动悬浮窗
```

> 数据源为境外公开 API，国内网络可能需要代理。

`setup_data.py` 可拆开执行（某步失败后可单独重跑）：

```bash
python fetch_ambr.py      # 基础数据：角色/武器/圣遗物/材料/成就
python fetch_guides.py    # 关系表：专武/推荐圣遗物/主词条/配队/命座使用率
python rag.py rebuild     # 构建 RAG 向量索引
```

## 数据说明

## AI 增强（可选）

点击悬浮窗标题栏 **AI** 按钮，填入服务商与 API Key（DeepSeek / 通义千问 / 智谱 GLM，均支持 OpenAI 兼容接口）即可启用 Agent 多工具问答。未配置时助手保持离线检索模式，功能不退化。

- API Key 只保存在本地 `settings.json`（已加入 `.gitignore`）
- 每次 Agent 问答成本约 0.03~0.08 元（视模型而定）
- 建议同时开启"多轮对话历史"，Agent 才能理解省略主语的追问

## 日志与统计

点击标题栏 **日志** 按钮查看：

- **问答日志**：每条问答的完整决策轨迹（命中层级、耗时、RAG 就绪状态、Agent 工具调用参数），双击查看完整 JSON
- **统计**：命中分布、未找到问题 TOP、平均耗时、Agent 工具使用情况

日志实时追加到 `logs/qa.jsonl`，可配合分析定位"没找到"的根因（数据缺失 / 匹配缺陷 / 检索未就绪）。

## 常见问题

**Q：拉取数据失败 / 超时？**
数据源在境外，需要代理。确认网络可访问 `gi.yatta.moe` 后重跑 `setup_data.py`。

**Q：某个新角色没有专武 / 推荐圣遗物？**
关系表来自安柏计划的角色指南（Genshin Wizard），数据源尚未收录的过新角色会缺失。可等数据源更新后重跑 `fetch_guides.py`，或在 `data/relations.json` 中手动补充（注意下次抓取会覆盖该角色条目）。

**Q：回答被截断 / 显示不全？**
- 数据层：`llm.py` 的 `max_tokens`（默认 1600）控制 LLM 输出上限，可调大
- 显示层：聊天区使用 `QTextBrowser`，长文本自动完整显示；如仍异常请通过"日志"面板查看 `reply_len`

## 目录结构

```
main.py            悬浮窗主程序（UI + 检索流程 + 日志）
rag.py             检索层（字段匹配 / RAG 索引 / 关系表）
knowledge.py       通用问答库（元素反应等）
llm.py             LLM 调用（OpenAI 兼容，支持 function calling）
agent.py           Agent 层（工具定义 + 对话循环）
fetch_ambr.py      数据拉取脚本（安柏计划）
fetch_guides.py    关系表生成脚本（角色指南）
setup_data.py      一键数据准备
docs/              数据目录（由脚本生成，不入库）
data/relations.json 关系表（由 fetch_guides.py 生成，不入库）
index/  models/     RAG 索引与向量模型（自动生成，不入库）
logs/              问答日志（不入库）
```
